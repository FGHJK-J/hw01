# 八皇后问题求解器 (hw01)

## 项目简介

本项目实现了一个高效的八皇后问题求解器，使用回溯算法来寻找所有可能的解决方案。八皇后问题是一个经典的组合优化问题，要求在N×N的棋盘上放置N个皇后，使得任意两个皇后都不在同一行、同一列或同一对角线上。

## 功能特性

- 支持任意大小的N皇后问题求解
- 使用回溯算法高效搜索所有可能的解决方案
- 提供命令行接口，支持自定义棋盘大小
- 实时性能统计，显示求解时间
- 美观的解决方案可视化
- 完整的单元测试覆盖

## 安装和使用

### 环境要求
- Python 3.6+

### 基本使用

1. **运行默认的8皇后问题**
   ```bash
   python src/eight_queens.py
   ```

2. **指定棋盘大小**
   ```bash
   python src/eight_queens.py 4  # 运行4皇后问题
   python src/eight_queens.py 6  # 运行6皇后问题
   ```

3. **运行单元测试**
   ```bash
   python -m unittest tests/test_eight_queens.py -v
   ```

## 算法说明

本项目使用**回溯算法**来求解八皇后问题：

1. **逐行放置**：从第一行开始，逐行尝试放置皇后
2. **安全性检查**：对于每个位置，检查是否与已放置的皇后冲突
3. **回溯机制**：当遇到无法继续的情况时，回溯到上一步，尝试其他可能性
4. **解决方案收集**：当所有行都放置完成时，记录一个解决方案

## 性能表现

- **时间复杂度**：O(N!)，最坏情况下需要尝试所有排列
- **空间复杂度**：O(N)，主要消耗在递归调用栈和棋盘存储
